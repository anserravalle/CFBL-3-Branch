# Letters from the Practice — Monthly Newsletter

Reference copies of the Center for Balanced Living monthly newsletter. These
HTML files are **email design references** — the newsletter is actually sent
through **Shopify Email** (Marketing → Create email), which is block-based.

## Files
- `letters-from-the-practice-TEMPLATE.html` — the **blank, fillable** template.
  Open it to see the layout; copy the structure when building each month.
- `2026-07-finding-the-right-words.html` — the **July 2026** issue (archived).
- Add one file per month going forward (e.g. `2026-08-...html`).

## Brand colors (heading text + buttons)
- Clinical / practice — Navy `#2B5275`
- CFBL Institute — Green `#3D5A52`
- MUSA — Maroon `#6E1F23`
- Accent / divider — Terracotta `#9D654E` / Sand `#EED9C5`

## Monthly workflow (Shopify Email)
1. Marketing → Create email → **Your templates → "Letters from the Practice"**
   (save the build once via the editor's **Save as template** option).
2. Replace the `[bracketed]` placeholders; update the title, "Month Year",
   and the inbox preview line.
3. Paste this month's MUSA/blog link into the MUSA button.
4. **Send test**, check links + colors, then **Send**.
5. Save a copy of the filled HTML here as `YYYY-MM-...html` for the archive.

> Shopify Email adds the unsubscribe link + business address footer
> automatically, so those don't need to be built by hand.
